### 2. Narrative

As a mortgage customer, I want a supported answer and its source references delivered to me directly, so that I can read the answer without first reaching a representative.

### 3. Acceptance Criteria

1. Given the product receives one customer question and the library of articles marked approved, when the hidden expected result is supported, then the recorded set is exactly supported.
2. The product does not receive the expected result, and it does not receive a pre-chosen set of matching articles. It searches the approved library.
3. The test can observe this order: submit, then a classification outcome, then source references drawn from approved knowledge, then a draft, then direct delivery to the customer. The customer is not required to see the recorded reasons. The test reads the recorded set.
4. The customer receives the answer and its source references. Every source reference resolves to an article in the approved library the product searched. A source reference that does not resolve to an approved article fails the test.
5. Supported means the approved knowledge supports the answer, the question does not require customer-specific loan information, and the answer can be determined to be safe. Direct delivery is allowed only when the recorded set is exactly supported.
6. No approval item is created. The representative does not act before the customer receives the answer. An approval step on this supported answer fails the test.
7. This is the only customer success path. Knowledge articles used by the test are fixtures. The path does not call a live mortgage servicing platform, CRM, Salesforce, Zendesk, or any other system of record.
8. The fixture set includes one question whose hidden result is supported, and that question passes criteria 1–7. One question is the smallest set that makes this outcome observable. It is not a volume target. The escalation fixtures are US-004.
9. Pass or fail does not depend on ROI, savings, complaint reduction, a satisfaction gain, a containment rate, replacement of a servicing platform, or a duration that has no sourced limit.

### 4. Scope Notes

- **In Scope for MVP**: Direct delivery of one supported answer and its source references; a recorded set of exactly supported; source references that resolve to the approved fixture library; no approval item; fixture data only; one supported question in the fixture set.
- **Deferred**: A second customer success path. Review of a supported answer by a representative. A live system of record. An accuracy check beyond the source reference (MP-03). Any latency, cost, volume, readability, satisfaction, or ROI target. The waiting state and the approval gate are US-003 and US-004.
